# KingBet
Frontend y Landing Page: Next.js (App Router) con React y Tailwind CSS. Ideal para SEO en la landing page y rendimiento instantáneo en las calculadoras.

Backend (Lógica de Negocio): NestJS. Manejará la lógica compleja de asignación de operadores, validación estricta de las calculadoras y la administración de ofertas HTML.

Base de Datos y Tiempo Real: Supabase (PostgreSQL). Proporcionará la base de datos relacional, subscripciones por WebSockets para el tablón de ofertas y la capa base de autenticación.

Entorno de Desarrollo Local: Configuración del workspace directamente en el editor Cursor, utilizando Podman para contenerizar la base de datos local y el backend en NestJS durante el desarrollo.
